Altering table names and the column names is a common operation in SQL. 
The `ALTER TABLE` statement allows you to add, delete, or modify columns in an existing table.
syntax for table name change:
```sql  
alter table old_table_name rename new_table_name;
```
syntax for column name change:
```sql
alter table table_name change old_column_name new_column_name datatype(size);
```

DML (Data Manipulation Language) commands are used to manipulate data in the database. 
The most commonly used DML commands are `INSERT`, `UPDATE`, and `DELETE`.

Insert command is used to add new records to a table. The syntax for the `INSERT` command is as follows:
```sql
insert into table_name (column1, column2, column3, ...) values (value1, value2, value3, ...);
```

inserting multiple records at once:
```sql
insert into table_name (column1, column2, column3, ...) values 
(value1, value2, value3, ...),
(value1, value2, value3, ...),
(value1, value2, value3, ...);
```

update command is used to modify existing records in a table. The syntax for the `UPDATE` command is as follows:
```sql 
update table_name set column1 = value1, column2 = value2, ... where condition;
```

delete command is used to remove existing records from a table. The syntax for the `DELETE` command is as follows:
```sql
delete from table_name where condition;
```
1. delete age = 17 # delete from students where age = 17;   
2. delete dept = chemistry # delete from students where dept = 'chemistry';
3. delete empid = e005 # delete from students where empid = 'e005';
4. delete lastname = 'arjun'   # delete from students where lastname = 'arjun';

truncate command is used to remove all records from a table, but it does not remove the table itself. 
The syntax for the `TRUNCATE` command is as follows:

truncate table table_name;

Important interesting points about truncate command:
1. Truncate is faster than delete because it does not generate individual row delete statements.
2. Truncate resets any auto-increment counters on the table.
3. Truncate cannot be rolled back in some databases, so use it with caution.
4. Truncate does not fire any delete triggers that may be defined on the table.
5. Truncate is a DDL command, while delete is a DML command.
6. Truncate is more efficient for large tables because it deallocates the data pages 
used by the table, while delete removes rows one at a time.
7. Truncate is not allowed on tables that are referenced by foreign key constraints, 
while delete can be used with cascading deletes to remove related records in other tables.
 
Important interview questions:

DROP vs TRUNCATE vs DELETE:

1. DROP removes the table structure and all its data, while TRUNCATE removes all data but keeps the table structure intact, 
and DELETE removes specific rows based on a condition.
2. DROP is a DDL command, while TRUNCATE and DELETE are DML commands
3. DROP cannot be rolled back, while TRUNCATE and DELETE can be rolled back in some databases.
